# 요구사항 정리

> 대본(드라마/영화) → LLM + RAG 분석 → 촬영용 차량 렌트 견적서 자동 생성 서비스
> 상태: 초안 (미결 사항은 문서 끝 "질문 목록" 참고)

## 1. 목적과 사용자

| 구분 | 내용 |
|---|---|
| 서비스 목적 | 제작사가 보낸 대본에서 촬영에 필요한 차량을 뽑아 보유 차량과 매칭하고 견적서를 자동 생성 |
| 주 사용자 | 렌트 회사 영업/견적 담당자 (대본을 받아 업로드, 견적서 검토/수정) |
| 간접 사용자 | 제작사 (견적서를 전달받음. 직접 로그인 여부는 미정 → 질문 Q1) |
| 현재 단계 | 실제 대본 미투입. 가짜 샘플 대본으로 개발 |

## 5. 비기능 요구사항

- **보안/기밀**: 대본은 제작사 기밀. `data/scripts/`에만 저장하고 git에 올리지 않음. 접근 권한 통제.
- **외부 LLM 전송**: 외부 LLM API로 대본을 보내도 되는지 계약 확인 필요 (Q3). 불가 시 로컬/사내 모델 필요.
- **비동기 처리**: 대본 분석은 오래 걸리므로 업로드 후 백그라운드 처리, 상태 조회.
- **재현성/추적**: 분석 결과에 모델 버전·프롬프트 버전 기록 (추후 LangSmith 연계).
- **정확도**: LLM 결과는 항상 사람이 검토·수정 가능해야 함 (자동 확정 금지).
- **개발 데이터**: 가짜 샘플 대본으로 개발·테스트.
